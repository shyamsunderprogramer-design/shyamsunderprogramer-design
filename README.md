### 👨‍💻 About me

I design, secure and automate multi-cloud platforms on **Azure and AWS**. I started as a
Java full-stack developer and grew into cloud and DevSecOps architecture, so I build
platforms the way a developer would want to use them.

- **Infrastructure as code** — reusable Terraform modules and ARM templates, with tfsec,
  Checkov and OPA Gatekeeper keeping every environment in policy.
- **CI/CD and GitOps** — GitHub Actions, Azure DevOps, Jenkins and Argo CD pipelines with
  blue-green, canary and automatic rollback.
- **Containers** — EKS, AKS and OpenShift with Docker and Helm; RBAC, network policies and
  Pod Security Standards for zero-trust runtime.
- **Security and compliance** — Snyk, Trivy, SonarQube, Vault and KMS in every pipeline,
  with HIPAA and FedRAMP evidence collected automatically.
- **Observability** — Prometheus, Grafana, ELK, Datadog and CloudWatch.
- **AI on the side** — local-first AI apps and agents in Python.

### 🌟 Featured projects

#### 🤖 [AI Job Applier](https://github.com/shyamsunderprogramer-design/AI_Assistant_Job_Applier)
A personal job-search assistant. It finds company job boards across Greenhouse, Lever,
Ashby, Workday, Workable and more (6,800+ boards), ranks every posting against your
resume, and tailors the resume per job **without inventing anything**: each requirement is
matched to a line in the resume, gaps are listed honestly, and the .docx and PDF are
checked page by page.
<br>`Python` `Flask` `SQLite` `Playwright` `Claude` `Ollama`

#### 📝 [AI Note Taker](https://github.com/shyamsunderprogramer-design/ai-note-taker)
A privacy-first AI notepad that runs entirely on your machine: local speech-to-text,
real-time transcription, a floating overlay and screen-capture protection.
<br>`Python` `Electron` `Local AI`

#### 🎛️ [Red Hat OpenShift AI + NVIDIA GPU Labs](https://github.com/shyamsunderprogramer-design/RedHat-AI-Labs)
A 48-hour proof of GPU workloads on an OpenShift-style cluster: NVIDIA GPU Operator with
MIG, DCGM metrics into Prometheus and Grafana, PyTorch training and Triton inference.
<br>`Kubernetes` `NVIDIA GPU Operator` `PyTorch` `Triton` `Prometheus`

#### 🧠 [My First Agent](https://github.com/shyamsunderprogramer-design/my_first_agent)
Building AI agents on Gemini with Google's Agent Development Kit (ADK) for Python.
<br>`Python` `Gemini` `Google ADK`
